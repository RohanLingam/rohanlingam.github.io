I would love for other engineers to replicate these builds and send me feedback on my instructions! Projects in progress are highlighted.

Programmable Delay Line on RFSoC 4x2 Kit.
Rohan Lingam, David W. Hawkins
JPL Div. 363F, 2026
project page / report / code

A programmable, modular delay line that functions as an active calibration source for the TREx (Tomographic Radar Experiment) project. Radar engineers can choose a fine, course, large, and fractional delay. I built this over the course of my internship at the Jet Propulsion Laboratory.

Brushless Motor Driver from Scratch
Rohan Lingam
Course project, EE 101, 2025
project page / code

A 40 V, 15 A field-oriented-control driver built around an STM32G4, with current sensing, gate drive, and a protection scheme that survived a stalled rotor.

2.4 GHz Patch Antenna Array
Rohan Lingam, Advisor Name
Undergraduate research, 2025
code / writeup

Designed, simulated, and measured a 4-element patch array on FR-4. Measured gain landed within 0.8 dB of the HFSS model, which felt like a miracle at the time.
