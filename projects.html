Programmable Delay Line on RFSoC 4x2 Kit.
Rohan Lingam, David W. Hawkins
JPL Div. 363F, 2026
project page / report / code

A programmable, modular delay line that functions as an active calibration source for the TREx (Tomographic Radar Experiment) project. Radar engineers can choose a fine, course, large, and fractional delay. I built this over the course of my internship at the Jet Propulsion Laboratory.

Compact, Low-Cost Antenna Portfolio for Wideband Radio-Glaciological Sounding
Rohan Lingam, Daniel F. May, Dustin M. Schroeder
IGARSS 2026, 2026
code / writeup

A low-cost, modular antenna portfolio spanning 1 MHz to 1 GHz designed for field-deployable radio-glaciological sounding. Rather than optimizing a single large antenna, this project provides a set of compact, predominantly planar PCB antennas. Includes log-periodic dipole array, Vivaldi, planar bowtie, and other low-frequency prototypes, allowing researchers to mix and match antennas in the field.

LoRa-Based Environmental Monitoring Node
Rohan Lingam
Course project, EE 156, 2026
project page / code

Designed, brought up, and tested a custom PCB solution for a LoRa-based environmental monitoring node using a Feather M4 microcontroller, BME688 sensor, and RFM95CW transceiver module. Capable of measuring live weather telemetry, the module transmits packets wirelessly every 5 seconds over a 917 MHz channel. The module successfully demonstrated round-trip transmission from over 2 miles from the Stanford Dish to a repeater at the Packard EE building.
